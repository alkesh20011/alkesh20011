I build backend systems, and I spend most of my spare hours on a long-running effort to render classical Vedic astrology as software that holds up to scrutiny — Swiss Ephemeris calculations, traditional divisional chart logic, and no ungrounded approximations in between.

Currently deepening enterprise Java and Spring Boot, and starting the Advanced Management Programme in Business Analytics at the Indian School of Business in July 2026.

<br/>

## Selected work

**VedaJyotish AI** — A full-stack Vedic astrology engine. Lagna/D1, D9, D10 and D60 chart computation on Swiss Ephemeris, Vimshottari Dasha periods, dynamic Panchang, and chart rendering decoupled into a pure-Python SVG layer. PostgreSQL-backed with feedback-weighted refinement.
<sub>Python · Flask · pyswisseph · PostgreSQL</sub>

**AetherOS** — A desktop operating system rebuilt as a browser interface, serving as a personal portfolio. Window management, gesture handling hardened for mobile, and debounced audio-visual feedback throughout. → [alkesh-site.vercel.app](https://alkesh-site.vercel.app)
<sub>JavaScript · CSS · Vercel</sub>

**UNIP** — An assessment platform on a fully serverless backend: Lambda-based payment verification through SQS, asynchronous report generation, S3 storage and SES delivery, with IndexedDB-backed progress persistence on the client and end-to-end coverage in Playwright.
<sub>PHP · AWS Lambda · SQS · S3 · SES</sub>

**Astrology Bot** — A self-hosted inference service running open-weight models on personal VPS infrastructure, bringing the above calculation work into conversational form without third-party dependencies.
<sub>Ollama · Docker · n8n</sub>
